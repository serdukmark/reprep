## AUD-005: потерян ответ после сохранения
- Воспроизведение: Playwright route.fetch действительно записывает новый черновик, затем route.abort теряет ответ; повтор кнопки создавал второй экземпляр. lost-response-before.json:2 вместо1.
- Исправление: клиент генерирует идентификатор операции нового черновика; сервер получает стабильный ID в рамках преподавателя, возвращает уже созданную работу, а при изменённом содержимом отвечает409. Не нужна миграция; старые клиенты без ключа работают как раньше. Ключ операции исключён из хранимого содержимого/ответа API.
- lost-response-after.json: passed. tests/test_create_retry.py: конкурентный повтор, изоляция преподавателей, конфликт содержимого, повтор после публикации. scripts/test_create_retry_mutations.py: намеренный возврат случайного ID пойман.
