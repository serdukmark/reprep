## Резервное копирование

Локально: `.venv/bin/python -m apps.server.backup backup --output artifacts/backups/snapshot.sqlite3`. Проверка: `... verify --source artifacts/backups/snapshot.sqlite3`. Восстановление: `... restore --source artifacts/backups/snapshot.sqlite3 --output artifacts/restored.sqlite3`. Живую БД команда не перезаписывает. Для Docker модуль доступен в образе; путь /app/data относится к volume. Backup содержит учебные данные: не коммитить/не публиковать; сроки хранения ещё согласовать.
