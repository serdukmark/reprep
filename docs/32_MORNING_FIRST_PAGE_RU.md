# Утро: начать с этой страницы

**Сейчас:** локальное демо работает. Единая API-репетиция с живым Qwen прошла за21,77 с (52 шага). Это не ручная репетиция и не MAX. Ночью кликов/ввода в окна, туннеля, публикаций и MAX-вызовов не было.

## Первые десять минут

1. **Перевыпустить MAX-токен в кабинете.** Поменять только `MAX_BOT_TOKEN=...` в корневом `.env`. `token.txt` — старый файл владельца, приложение его не читает. Не вставлять новый токен в чат или Git. Контейнер хранит настройки до перезапуска: обычного `docker compose restart` недостаточно для нового env; команда ниже применит изменение. После ротации повторно зарегистрировать webhook — его секрет производный от токена. [Точный объём инцидента](33_REHEARSAL_REPORT_RU.md).
2. **Для MAX:** выбрать уже доступный HTTPS, записать origin в `PUBLIC_BASE_URL`; URL MiniApp указать в кабинете бота. Два разных тестовых MAX-аккаунта: один преподаватель, другой ученик; только вымышленные имена и работы. Одному аккаунту роль повторным входом не поменять. Если HTTPS ещё нет, десяти минут на полноценный MAX не обещаем.
3. **Запустить подготовленный локальный продукт:**

   ```bash
   cd /Users/pozitiv4500/Goool/Max_fuck_you
   bash scripts/demo.sh --prepared
   ```

   Открыть http://127.0.0.1:8000. Учитель и ученик — разные вкладки. Ничего собирать руками не нужно. При ошибке готовности: `.venv/bin/python scripts/monitor.py`.
4. **MAX подключает владелец:** после HTTPS и ротации выполнить `.venv/bin/python scripts/setup_max.py --apply`, снова команду запуска, затем `.venv/bin/python scripts/setup_max_subscription.py --apply`. Настройка включает реальные ответы бота; ночью эти команды не запускались. [Подробности](26_MAX_START_RU.md).
5. **Важная граница AI:** настоящий вход MAX пока создаёт обычный аккаунт, которому внешний AI запрещён текущей политикой. Локальные демо-роли позволяют проверить живой AI на синтетике, но не доказывают связку с MAX-идентичностью. Для полного MAX→AI-прогона нужно отдельное решение владельца по допустимым данным/тестовым аккаунтам (N-03); не переключать общую политику незаметно.

## Что показать за 3–5 минут

Новая работа Саше → сохранить ответ → сдать → показать статус обработки → Qwen-разбор → преподаватель читает и подтверждает/исправляет → ученик видит объяснение и основание прогресса. В измерении генерация заняла12,77 с, проверка8,76 с; это фоновые операции, не зависание страницы. При отказе AI — явный ручной разбор, без заявления «живой AI сработал». Каталог/группы/родительский кабинет показывать после главного цикла, если осталось время. [Пошаговый сценарий](27_DEMO_SCRIPT_RU.md).

Сначала: новый токен, постоянный HTTPS, два аккаунта и разрешённый режим данных для MAX→AI. Затем: провайдеры/доступы платежей, видео и календаря; границы общей проверки; методика универсального AI. Эти функции ночью не разрабатывались. [Варианты, стоимость и текущие решения](15_OPEN_QUESTIONS.md#остатки-поставлены-на-утро-по-прямому-указанию-владельца).
