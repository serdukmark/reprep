## Реализовано

- Серверный GET `/api/relationships/{id}/learning-journey`, все опубликованные
  работы связи, без ограничения списка в 100 элементов. Только агрегаты,
  серверная авторизация; родителям/чужим пользователям доступ не добавлен.
- Серия с рисованным SVG-огоньком, фактическая недельная сводка, честные пустое,
  ошибочное и недостаточное состояния; обновление раз в минуту/при возврате вкладки.
- «Мой путь»: галочка последней верной проверки, текущий узел, информационный
  замок предпосылок. Порядок/ветки только из графа преподавателя. Без графа —
  имеющаяся история; без истории — пустое состояние. Доказательства по клику.
- Исправлена потеря более свежего результата при разных регистрах названия
  навыка: граф суммирует evidence, отдаёт точные `evidence_ids`. Старый `/progress`
  остаётся совместимым; проверены оба перехода верно→неверно и неверно→верно.
- Полоса заполнения `0/3 → 1/3 → 2/3 → 3/3` по непустому тексту/TXT. Она не
  означает правильность или успешное сохранение. Существующая форма сохранена.
- «Отправлено» только после успешного POST. При отказе последующего GET остаются
  подтверждение и отправленные ответы; форма повторно не открывается. Медаль
  недели берётся из серверных фактов, отказ сводки не отменяет отправку.
- SVG вместо символьных декораций главной; существующий SVG-граф принимает
  согласованные токены с сохранением прежних цветов до интеграции темы.

Требования: **FR-PROG-001/002/004/006/007, FR-SUB-002/003/004/005**, существующий
TEAM-104/ADR-011. Правила и архитектурное решение: [ADR-014](adr/014-learning-journey.md).

## Правила серии и почему

Считается первая сдача каждой опубликованной работы: не позже срока — +1,
пропуск срока — сброс. Порядок дедлайнов; одинаковые сроки составляют группу,
пропуск в ней обнуляет группу. Это исключает зависимость от случайного ID.
Будущие несданные работы приостанавливают рост без штрафа; ранние сдачи уже
считаются. Дни без работ нейтральны. Повторы/возвраты/ожидание проверки не влияют
на первую сдачу; качество ответа не подменяет пунктуальность. Без дедлайна
работа не участвует. При недостатке фактов числа и награда не показываются.

Неделя — понедельник–воскресенье **UTC**, явно указано в интерфейсе. Срок работы
определяет попадание в неделю. Сдано и сдано в срок считаются отдельно; медаль
означает все работы отправлены, не все верны или своевременны. При нуле работ
медали нет. Новое назначение меняет текущую сводку.

## Что осталось и ограничения

- Инженерное ревью, объединение с оформлением и последующая проверка MAX на
  устройствах. На стенде эта механика не проверялась по прямому запрету владельца.
- Перенос/отмена/освобождение от дедлайна: отсутствуют в модели. Работа,
  опубликованная с уже истёкшим сроком, сразу считается пропущенной. Это открытый
  вопрос OQ-JOURNEY-002, а не скрытая льгота.
- Локальный часовой пояс недели — OQ-JOURNEY-001; сейчас явный UTC.
- Пошаговый мастер «одно задание на экран», отдельный новый экран «Разбор» с
  «Почти/Верно» и кнопкой исправления не переносились. Подтверждённые комментарии
  и доработка после возврата продолжают работать в существующем P0.

## Проверить вручную локально

После подготовки зависимостей по README выполнить `npm run build`. Запустить
свою копию сервера с синтетической БД и LocalRules, например:

```sh
.venv/bin/python -c 'import uvicorn; from apps.server.main import create_app; from apps.server.config import Settings; uvicorn.run(create_app(Settings(database="artifacts/journey-manual.sqlite3", environment="test", demo=True, learning_journey_enabled=True)), host="127.0.0.1", port=18741)'
```

1. Открыть localhost:18741, войти учеником: пустая серия; «Мой путь» показывает
   существующие данные либо честное пустое состояние.
2. В другой вкладке преподавателя назначить работу со сроком и задать граф в
   «Ученики». Учеником заполнить ответы/TXT: полоса меняется, отправить работу.
3. Увидеть «Отправлено» и серверную серию. Медаль — только если действительно
   сданы все работы со сроком на эту неделю у выбранного преподавателя.
4. Преподавателем проверить/исправить работу. Учеником открыть «Мой прогресс» →
   «Мой путь», выбрать навык: проверить статус, предпосылки и источники.
5. Вернуть другую работу, исправить, отправить повторно: старая попытка неизменна,
   серия за ту же работу второй раз не увеличивается.
6. Перезапустить с `learning_journey_enabled=False`, обновить страницу: новые
   виджеты скрыты, прежний граф и P0 доступны. Ничего удалять из базы не требуется.

Автоматический новый browser-suite сбрасывает только синтетическое демо на
изолированном loopback-сервере. Не направлять тесты на действующий продукт.
