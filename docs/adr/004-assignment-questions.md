# ADR-004: Вопросы к AI по заданию с подтверждением преподавателя

- Status: accepted as reversible implementation
- Date: 2026-09-21
- Related requirements: AI-USE-006, TEAM-039/056
- Related questions: политика обратной связи и пилотных данных

## Context

Команда просила вопросы к AI внутри учебного задания. Неограниченный универсальный чат и автоматические итоговые оценки остаются отрицательными ограничениями. Новый путь не должен терять вопрос при отказе провайдера или обходить общий бюджет.

## Decision

Отдельная устойчивая очередь ai_questions: queued → processing → awaiting_review → published. По истечении lease вопрос остаётся преподавателю без повторного платного запроса. Ответить вручную можно до окончания AI; поздний результат не перезапишет подтверждённый ответ. Отправка вопроса идемпотентна, до 20 вопросов на ученика за UTC-день, общий AI_DAILY_LIMIT разделяется с проверкой работ.

Модель получает один prompt/skill/options/hint и вопрос, максимум два разрешённых TXT; эталоны, рубрики, переписка с человеком и чужие ответы не передаются. Контекст ограничен 30 KB. Отдельный versioned prompt question-v3; JSON валидируется. Условия использования реальных данных и $1/M для входа/выхода те же, что у основной проверки.

Ученику не отдаётся черновик модели. Преподаватель берёт текст, редактирует и подтверждает; опубликованный текст неизменяем. Вопрос не создаёт evidence и не меняет успеваемость. Без настроенного OpenRouter модель честно недоступна, вопрос остаётся человеку.

## Alternatives

- Немедленный показ AI: быстрее, но нельзя гарантировать отсутствие ложного объяснения или выдачи решения; не выбран.
- Только человеческое обсуждение: работает без модели, уже реализовано отдельно; не заменяет просьбу AI-USE-006.

## Validation and rollback

tests/test_questions.py: scope, конфликты, провайдер/структура/сеть, стоимость, реальные данные и конкурентные ученики. scripts/test_question_mutations.py проверяет чувствительность тестов к поломкам. Живой прогон нового AI-пути и UI отдельно фиксируются в docs/31. Откат требует backup; таблицу с вопросами автоматически не удалять.
