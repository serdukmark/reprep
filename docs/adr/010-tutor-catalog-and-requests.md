# ADR-010: Каталог и подбор репетитора

Status: accepted as reversible owner-authorized implementation, 2026-09-21. TEAM-101/105, VOICE-4.

Преподаватель сам включает анкету: заголовок, описание, до 10 предметов, цена/длительность занятия. Профиль хранится с revision; изменение из старого окна отклоняется. Каталог требует входа и разделяет синтетические/реальные аккаунты. Поиск по имени/предмету и максимальной цене; нет выдуманного рейтинга или подтверждённого качества анкет.

Ученик отправляет заявку по одному предмету. Сервер проверяет видимость, предмет и revision предложения; изменившиеся условия требуют обновления. Цена/длительность фиксируются в заявке. Только согласие преподавателя создаёт связь для обычного учебного сценария. Отклонение не создаёт её; повтор запроса/решения идемпотентен. Ответ преподавателя виден в приложении, внешних сообщений нет.

Ни оплата, ни комиссия, ни подписка не проводятся. Предельная цена поля — техническая валидация, не выбранный тариф продукта. Это локальное техническое демо без подтверждённого спроса/верификации преподавателей. Каталог ограничен первыми 500 профилями и 100 результатами, заявки — 100 записей и 10 созданий ученика в UTC-день; полноценная масштабная выдача пока не реализована.

Миграция 7 добавляет отдельные таблицы. API в marketplace.py; тесты test_marketplace.py и browser/catalog.spec.ts. Мутации проверяют скрытую анкету, устаревшие условия и связь при отказе.
