# Черновик до первого ученика — 24.09.2026

[CONFIRMED] Владелец сообщил: новый преподаватель не может нажать «Создать задание». Причина — интерфейс требовал уже принятого приглашения ученика. Исправление позволяет сначала подготовить и сохранить работу; связь с учеником обязательна только для назначения.

В SQLite assignment.relationship_id теперь допускает NULL для черновика. Миграция 11 переносит существующие строки, восстанавливает индексы, проверяет внешние ключи. API сохраняет прежний строковый формат: пустая строка означает «ученик не выбран». Неназначенный черновик доступен только своему автору. Сервер запрещает публикацию без ученика. Реальные и демонстрационные аккаунты не смешиваются, чужую связь привязать нельзя. Миграция меняет схему, перед выкаткой создана приватная SQLite backup с проверкой целостности.

Общий код работает в MAX и во временном тестовом Telegram. Проверки: tests/test_unassigned_drafts.py — новый преподаватель, приватность, сохранение/назначение после приглашения, перенос существующей базы и повторный запуск миграции.
