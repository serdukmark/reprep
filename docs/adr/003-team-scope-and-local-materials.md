# ADR-003: Полный список команды и обратимые локальные решения

- Status: accepted (временные решения можно переиграть)
- Date: 2026-09-21
- Owners: владелец задал расширение; реализацию проверяет инженер команды
- Related open questions: N-12–N-14, ротация MAX-токена
- Related requirements: TEAM-001–112, FR-SUB-002, FR-MAT-002/003

## Context

Владелец прямо поручил реализовать все предложения коллег, включая прежде отложенные. Ограничения на внешнюю публикацию, платежи, реальные персональные данные и ночной запуск MAX сохраняются. docs/03 и решение D-N11 обновлены.

## Decision

Автосохранение через две секунды, прекращение повторов при ошибке до ручного действия. Рекомендации только по подтверждённым работам; предложенное задание остаётся черновиком. Аналитика считает события, не выдумывает учебный эффект.

Первый поддерживаемый файл — UTF-8 TXT до 60 KB в существующей приватной SQLite. Скачивание только после проверки связи с учеником и публикации задания. Для использования текста в AI требуется отдельный флаг преподавателя; не более двух материалов по 12 тысяч символов, общий предел контекста сохраняется. Материалы конкретного занятия не попадают в посторонние задания. Произвольные бинарные форматы/OCR не объявляются поддерживаемыми.

Профиль меняет только отображаемое имя. Приглашение сначала показывает преподавателя и предмет, затем ученик принимает или отклоняет одноразовый код. Граница демо/реальных аккаунтов сохраняется.

Индивидуальная программа хранится отдельно от evidence, её статусы не доказывают освоение навыка. Редактирует только преподаватель с проверкой ревизии; ученик не получает ссылки на черновые работы. Приватные сообщения хранятся по заданию, имеют ключ повтора и лимит отправки; это локальная коммуникация человека с человеком. Новые таблицы learning_plans/messages создаются идемпотентно (версия 3), демо-сброс удаляет только демо-записи.

## Alternatives considered

- Внешнее объектное хранилище и OCR: форматы шире, нужны поставщик/бюджет/политика данных; пока вопрос владельцу.
- Только ссылки: проще эксплуатация, не закрывает предложение загрузки файлов.
- TXT в SQLite: ограниченный формат, существующая изоляция/backup без нового сервиса; выбран обратимо.

## Consequences

Новые поля JSON имеют пустые/безопасные defaults; старые задания продолжают читаться. Публикации неизменяемы. Backup создаёт отдельный файл, restore не перезаписывает работающую базу. CI подготовлен, запуск в GitHub не проверен, push запрещён.

## Validation and rollback

pytest, browser autosave/materials и сборка клиента; точные результаты в docs/31. Возврат к предыдущему локальному коммиту возможен только после отдельного backup: новая версия данных может содержать файлы. Старый образ не следует использовать для правки новых записей без миграционного ревью.
