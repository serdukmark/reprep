# ADR-011: Граф навыков и метрики проверок

Status: accepted as reversible owner-authorized implementation, 2026-09-21. TEAM-104, CASE-22.

Преподаватель задаёт до 50 навыков и 200 направленных предпосылок. Циклы, неизвестные узлы и дубликаты отклоняются. Сохранение использует revision, ученик читает. SVG позволяет выбрать узел и посмотреть подтверждённые результаты; изменение графа не создаёт evidence.

Последний подтверждённый результат привязывается к навыку без учёта регистра. Предпосылки считаются подтверждёнными только когда каждая имеет последний результат correct. Это объяснимое правило, не измерение полного освоения и не автоназначение. Для предмета нужны связи преподавателя; универсальная база всех ЕГЭ не добавлена.

Аналитика: медиана времени от сдачи до решения преподавателя, число ожидающих работ, число сопоставленных результатов и исправлений относительно предварительного разбора. Сопоставление включает LocalRules, если именно они использовались. Время ожидания не равно времени ручной работы; расхождение не является независимым измерением точности AI.

Миграция 8 добавляет skill_graphs. Проверки: test_skill_graph.py, browser/skill-graph.spec.ts, две мутации (цикл и неподтверждённая предпосылка).
