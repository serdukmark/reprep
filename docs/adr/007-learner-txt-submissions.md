# ADR-007: TXT в ответе ученика

Status: accepted, reversible owner-authorized extension, 2026-09-21. TEAM-032, FR-SUB-004.

По указанию владельца реализовать предложения команды выбран TXT без нового провайдера. До трёх UTF-8 файлов суммарно 60 KB, по одному к числовому/текстовому заданию. Файл может заменить пустой текст ответа; выбор варианта требует обычного ответа. Имя не содержит пути, нулевые байты запрещены. Фото/PDF/OCR не реализованы.

Черновые файлы сохраняются атомарно с общей revision, преподавателю не видны. При сдаче создаётся независимый неизменяемый снимок; повтор с другими файлами отклоняется. История включает исходные байты текста и имя, возврат не переписывает прошлую попытку. Содержимое выводится текстом, никогда HTML.

Текст файлов добавляется к соответствующему ответу только в AI-контексте; оригинальный текст ответа в БД не меняется. Общий лимит контекста 60 KB, политика синтетики и лимит вызовов сохраняются. При превышении работа остаётся преподавателю без платного вызова.

Миграция 4 добавляет draft_files/submission_files с каскадным удалением по владельцу-объекту; старые таблицы/ответы не переписываются. Старые API-клиенты без attachments отправляют пустой набор; контракт замены черновика должен учитывать это. Старый клиент не должен редактировать черновик с файлами.

Проверено: tests/test_answer_files.py, browser/answer-files.spec.ts; три мутации проверяют подмену файла при повторе, потерю AI-контекста и чужой task ID. Не проверены независимая предметная точность модели на файлах и реальные MAX webview.
