# ADR-008: Родительский кабинет только для чтения

Status: accepted as reversible owner-authorized implementation, 2026-09-21. TEAM-112.

Отдельная неизменяемая роль guardian. Преподаватель приглашает взрослого к конкретной связи с учеником. Одноразовый код хранится только хешем, истекает через 72 часа; принятый доступ действует до отзыва. Другой взрослый не может повторно принять использованный код. Выдача не отправляет сообщений наружу.

Родителю доступны только сводка подтверждённых навыков и расписание. Нет оригинальных работ, материалов, переписки, финансов, эталонов и AI-черновиков. Основные ресурсы остаются закрытыми обычными проверками ролей/связей. Отзыв проверяется каждым запросом; UI обновляется каждые 5 секунд. Уже увиденные сведения нельзя технически «забрать обратно».

Реальное родство и законность выдачи доступа приложение не подтверждает. До утверждения владельцем процедуры GUARDIAN_DATA_APPROVED=false блокирует работу с реальными аккаунтами; синтетическое демо доступно. Родительская роль не является одновременной ролью ученика или преподавателя.

Миграция 5 расширяет CHECK users.role через транзакционные create/copy/drop/rename, сохраняет индексы/триггеры и проверяет foreign_key_check, не редактирует writable_schema. Источник процедуры: https://www.sqlite.org/lang_altertable.html#making_other_kinds_of_table_schema_changes. Перед обновлением рабочей базы сделан SQLite backup. Для отката старого кода нужна копия базы до миграции; новые данные обратный откат не поддерживает.

Проверки: tests/test_guardian.py — принятие, роли, изоляция, истечение, отзыв, чужой взрослый, граница реальных данных, миграция существующей базы. scripts/test_guardian_mutations.py обнаруживает намеренно сломанный отзыв в списке и подробном API. Браузерный статус отдельно в docs/31.
