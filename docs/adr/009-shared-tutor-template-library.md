# ADR-009: Пространство преподавателей и общая библиотека

Status: accepted as reversible owner-authorized implementation, 2026-09-21. TEAM-099.

Владелец создаёт пространство и выдаёт одноразовые коды коллегам. До 20 участников, 200 неизменяемых шаблонов. Владелец исключает участников, участник может выйти. Принятый код исключённого участника повторно не открывает доступ; для возвращения нужен новый код.

Преподаватель явно делится снимком условий, эталонов, критериев и подсказок своей работы. Общая библиотека не содержит идентификаторов учебных связей, дедлайнов, файлов, переписки, ответов ученика. Каждый участник копирует шаблон в собственный приватный черновик и публикует обычным путём. Идемпотентный повтор не создаёт вторую копию. Исключение не удаляет ранее созданную собственную копию.

Общие ученики, совместная проверка одной работы и права заместителя преподавателя пока не реализованы: выбран ограниченный вариант коллективной библиотеки. Это отдельный продуктовый вопрос N-22, а не неявный доступ ко всем ученикам коллеги. Новых внешних сервисов/платежей нет.

Миграция 6 добавляет таблицы без изменения существующих работ. API в apps/server/workspaces.py. Проверено tests/test_workspaces.py и browser/workspaces.spec.ts: коллеги → шаблон → личный черновик → исключение; мутации проверяют отзыв, утечку связи и автоматическую публикацию.
