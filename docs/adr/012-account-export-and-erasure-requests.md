# ADR-012: Экспорт и запрос удаления аккаунта

Status: accepted as reversible implementation, 2026-09-21. TEAM-094, CASE-24.

Экспорт JSON требует действующей сессии, содержит собственный профиль и связанные доступные записи, все попытки, материалы, программы/прогресс, сообщения/вопросы и созданные пользователем данные новых модулей. Ученик не получает эталоны и AI-черновики; преподаватель не получает неотправленные черновики ученика. Сессии, ключи и хеши приглашений исключены. Собственный MAX ID включён как персональное поле профиля.

JSON последовательно пишется во временный файл 0600, SQL-транзакция освобождается перед скачиванием, файл удаляется после передачи. После аварии процесса временный экспорт может остаться; очистку и срок хранения нужно включить в эксплуатационную политику.

Пользователь подтверждает запрос своим текущим именем и может отменить его. API не выполняет окончательное удаление. Операторский account_erasure сначала показывает dry-run, при --apply требует ACCOUNT_DELETION_APPROVED=true, повтор точного user-id и новый путь backup. Перед транзакцией создаётся SQLite backup; при ошибке удаления транзакция откатывается.

Из живой базы удаляются аккаунт, сессии, его учебные связи и зависимые работы, личные файлы, связанные сообщения/вопросы и записи новых модулей. Группы других преподавателей очищаются от удалённых связей. Независимые копии шаблонов коллег сохраняются; оператор должен проверить ранее поделённые тексты на персональные сведения. Резервные копии и чужие скачанные экспорты этим действием не стираются. Это не обещание юридически полного удаления всех копий данных.

Ночью операция применялась только к временным базам автоматических тестов. Рабочая база не удалялась. Сроки обработки запроса и хранения backup не выбраны: N-24. Миграция 9 добавляет deletion_requests.

Проверки: test_account_data.py — приватность экспорта, полная история, отмена, обязательная политика/backup, сохранение другого ученика и копии коллеги; browser/account-data.spec.ts — файл скачан, запрос создан и отменён; две мутации приватности/подтверждения обнаружены.
