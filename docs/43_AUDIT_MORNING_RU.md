# Утренний пакет аудита RePrep — 24.09.2026

**Аудит не завершён.** Основные пути подтверждены у 75 из 78 сценариев. В матрице вариантов: 316 прошли, 455 не проверялись, 87 неприменимы с объяснением. Это не процент полного покрытия приложения.

**Первое решение утром — окно выкатки защиты аккаунтов AUD022/AUD025/AUD032.** Локально на синтетике воспроизведён показ данных предыдущего аккаунта и сохранение его полей после выхода, а также восстановление прежнего кабинета через BFCache кнопкой «назад». Исправления проверены, но не опубликованы. Боевой инцидент этим не установлен. В этой работе стенд и его данные не менялись; push, deploy, живой MAX и окна владельца не использовались.

## Работает и проверено локально

- **173 серверных теста прошли после AUD029.** Два предупреждения библиотек; ошибок нет.
- **279/279 браузерных тестов прошли за 9,7 минуты после AUD032**, без пропусков и нестабильных повторов. Включены регистрация, переписка и пять настоящих BFCache-восстановлений всех ролей и неизменной сессии. Все пять BFCache-тестов также обнаружили намеренно отключённую защиту; каждый подтвердил `persisted=1`. Отдельно после общего прогона прошли **5/5**: BFCache без сети и четыре демо-входа. Это не завершённая матрица.

- **32 дефекта исправлены локально.** Для каждого сохранены падение до правки, успешный повтор и обнаружение намеренной поломки. Последние: безопасный повтор принятия приглашения; поздний ответ создания не возвращает закрытый редактор; повтор создания тренировки не даёт дубль; BFCache не восстанавливает прежний кабинет.
- Проверены смена аккаунта на основных экранах и в родительском кабинете, задержанные ответы и скачивания, права на чужие работы/материалы/планы/библиотеку/группы/оплаты. [Инвентаризация состояния](44_SESSION_ISOLATION_AUDIT_RU.md).
- Проверены обрыв сети, истёкшая сессия, потерянное подтверждение, две вкладки, генерация с задержкой/пустотой/мусором/отказом провайдера. Внешние AI и сообщения в этом аудите не вызывались.
- Сборка клиента `index-CvwJf8dK.js` прошла. Просмотрены выбранные кадры основных и мобильных экранов, исправленных профиля и напоминаний; каждый кадр каждого пути пока не просмотрен.

Проверки идут отдельным headless Chrome, одним worker, на синтетической SQLite. MAX/Telegram — симуляторы, AI — детерминированный тестовый провайдер. Все исправления остаются локальными; публикации нет. Секреты не включаются в Git, перед каждым коммитом запускается сканер.

## Что остаётся и что нельзя обещать на защите

- 455 вариантов матрицы ещё не проверены. [Карта всех ролей и путей](41_FULL_USER_AUDIT_RU.md), [подробный checklist вариантов](45_AUDIT_MATRIX_RU.md), [машиночитаемые доказательства](evidence/deep-audit/scenarios.json).

- Этот аудит не подтверждает качество настоящей модели, внешнюю доставку сообщений или политику обработки реальных данных детей.
- В UI нет отдельной роли организатора, экспорта CSV, плана в кабинете родителя и редактирования названия/времени уже созданного занятия. Платежи — ручные отметки; автоматические встречи, синхронизация календаря и прочие отложенные функции не выдаются за работающие.

## Решения владельца по приоритету

1. **Когда выкатить исправления?** Без дополнительных расходов: оставить локально до согласованного окна либо разрешить отдельную выкатку и проверку. Пока не публикую. Приоритет — защита смены аккаунта.
2. **Обязателен ли комментарий к жалобе?** Сейчас необязателен; можно потребовать его для ошибок/вредного разбора. Это выбор продукта, варианты и оценка — [АУД-Q2](15_OPEN_QUESTIONS.md).
3. **Как редактировать во время сохранения?** Сейчас поля блокируются до ответа; буфер последующих правок потребует примерно 2–4 часа, без расходов на сервисы. Пока оставлена блокировка и предупреждения об уходе; можно переиграть.

Для продолжения локального аудита ответов не требуется. Решения по живому MAX и реальным данным остаются у владельца.

## Повторить проверку

Только отдельная синтетическая база; модуль `audit_server` нельзя публиковать. Сейчас локальный сервер уже слушает 127.0.0.1:8017 — второй запуск не нужен. Для чистого запуска:

```sh
npm run build
.venv/bin/python -m uvicorn tests.audit_server:app --host 127.0.0.1 --port 8017 --no-access-log
```

Во втором терминале:

```sh
E2E_URL=http://127.0.0.1:8017 E2E_AUDIT=1 E2E_MAX_SIM=true E2E_FAULT_SIM=true E2E_FIXTURE_GENERATION=1 E2E_MAX_SDK_PATH=artifacts/max-web-app.js npx playwright test --workers=1
.venv/bin/python -m pytest tests -q --tb=no
```

Каждый браузерный тест сбрасывает только синтетическую базу. Сохранённый SDK используется для контрактной проверки; loopback Origin преобразуется тестовым wrapper в audit.invalid. Это не проверка боевого HTTPS/Origin.
