## Воспроизвести проверки
Только в отдельной локальной базе; тестовый сервер не публиковать и не использовать для реальных пользователей.

```sh
npm run build
.venv/bin/python -m uvicorn tests.audit_server:app --host 127.0.0.1 --port 8017 --no-access-log
```

Во втором терминале:

```sh
E2E_URL=http://127.0.0.1:8017 E2E_AUDIT=1 E2E_MAX_SIM=true E2E_FAULT_SIM=true E2E_FIXTURE_GENERATION=1 E2E_MAX_SDK_PATH=artifacts/max-web-app.js npx playwright test --workers=1
.venv/bin/python -m pytest -q
```

В режиме аудита база сбрасывается перед каждым тестом. `artifacts/max-web-app.js` — сохранённый официальный SDK для одного контрактного теста; его отсутствие не означает, что живой MAX проверен. Тестовый wrapper переводит loopback Origin в синтетический audit.invalid; правильность боевого Origin отдельная проверка.
