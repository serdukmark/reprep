**Аудит продолжается. В карте подтверждены основные пути 74 из 77 сценариев; три пункта остаются частичными или исключёнными. ## Что проверено

- **170 серверных тестов прошли**, два предупреждения библиотек о депрекациях. Отчёт: `artifacts/deep-audit/server-tests.xml`.
- **151 браузерный тест прошёл одним запуском за 7,1 минуты**, без пропусков и повторов. Это общий регресс после всех AUD001–020, включая формы после отзыва сессии, полный offline, вопросы, ограничения ввода, таймауты, потерянные подтверждения и две вкладки напоминаний.
- Дополнительно: 16 проверок обрыва чтения / отозванной сессии, изоляция редактируемого плана и графа при смене ученика, четыре проверки отказов экспорта и отменяемой заявки удаления; каталог после защиты от старого ответа — 18/18 с сопутствующими проверками.
- Ещё три новых теста прошли отдельно: отказ ученику в чужом плане и графе навыков, отказ сохранения проверки после отзыва сессии преподавателя с успешным повторным входом. Всего в наборе 154 теста; одним запуском подтверждены 151, три добавлены после него.
- Вход и регистрация трёх ролей в симуляторах MAX/Telegram; неверная и истёкшая подпись, дубликаты параметров, выход и отказ sessionStorage.
- Назначение → сдача → проверка → решение преподавателя → прогресс; возврат, повторная сдача, отклонение без оценки, файлы и история.
- Недоступность AI, пустота, мусор, задержка, слишком большой контекст; повтор до лимита и ручная проверка с сохранностью оригинала.
- Потеря ответа после записи на сервере, обрыв polling, две вкладки и конфликт редактирования, одновременные сдачи двух учеников.
- Группы, учебный план, граф навыков, каталог, обсуждения, экспорт JSON; отмена занятия, все отметки ручной оплаты и календарь ICS; валидация и скачивание TXT.
- Родитель: подмена ребёнка, отзыв доступа и обрыв сети; смена выбранного ребёнка при задержанном ответе. Коллега: копирование шаблона и отказ после исключения из пространства.
- Политики подсказок: эталон не показывается ученику, подсказки автора доступны согласно настройке, обратная связь появляется после решения преподавателя.

Проверки выполнены отдельным headless Chrome, одним worker, на синтетической SQLite. AI в этом аудите — детерминированный тестовый провайдер, без вызовов OpenRouter. Трассы кадров и шагов сохранены в `artifacts/deep-audit/*-traces`. Просмотрены 30 выбранных кадров основного цикла, родителя, коллег, каталога, групп, напоминаний, конструктора и графа; найден AUD015. Исправленный каталог просмотрен при ширине 390 px. ## Решения владельца

Блокеров для продолжения локального аудита нет. Утром нужны решения:

1. **Окно выкатки исправлений.** Пока оставлены локально, можно переиграть. Дополнительных расходов нет; до выкатки прежние ошибки остаются на стенде.
2. **Комментарий к жалобе.** Сейчас необязателен. Можно оставить так или сделать обязательным для сообщения об ошибке/вредном разборе. Варианты и оценки трудозатрат: [АУД-Q1/Q2](15_OPEN_QUESTIONS.md).

3. **Ввод во время сохранения.** Пока поля блокируются до ответа; альтернативный буфер новых правок потребует примерно 2–4 часа. Расходов на сервисы нет. Это обратимое решение АУД-Q3.

Прежние решения по живому MAX и политике реальных данных этим аудитом не закрываются.

## Повторить локально

Только отдельная тестовая база. Не публиковать модуль audit_server и не использовать реальные данные.

```sh
npm run build
.venv/bin/python -m uvicorn tests.audit_server:app --host 127.0.0.1 --port 8017 --no-access-log
```

Во втором терминале:

```sh
E2E_URL=http://127.0.0.1:8017 E2E_AUDIT=1 E2E_MAX_SIM=true E2E_FAULT_SIM=true E2E_FIXTURE_GENERATION=1 E2E_MAX_SDK_PATH=artifacts/max-web-app.js npx playwright test --workers=1
.venv/bin/python -m pytest -q
```

Перед каждым тестом синтетическая база сбрасывается. `artifacts/max-web-app.js` — сохранённый SDK для контрактной проверки. Тестовый wrapper переводит только loopback Origin в synthetic audit.invalid; это не проверка боевого HTTPS/Origin.
