# Утро после аудита RePrep — 24.09.2026

**Аудит продолжается. В карте подтверждён 51 из 77 сценариев; 26 остаются частичными или непроверенными.** Исправления только локальные: reprep.ru и боевые данные не менялись, push и deploy не выполнялись. Окна владельца не использовались.

## Что проверено

- **164 серверных теста прошли**, два предупреждения библиотек о депрекациях. Отчёт: `artifacts/deep-audit/server-tests.xml`.
- **81 браузерный тест прошёл одним запуском за 4,7 минуты**, без пропусков. После него прошли ещё **4 новых теста за 14,5 секунды**. Единого запуска всех 85 пока не было.
- Вход и регистрация трёх ролей в симуляторах MAX/Telegram; неверная и истёкшая подпись, дубликаты параметров, выход и отказ sessionStorage.
- Назначение → сдача → проверка → решение преподавателя → прогресс; возврат, повторная сдача, отклонение без оценки, файлы и история.
- Недоступность AI, пустота, мусор, задержка, слишком большой контекст; повтор до лимита и ручная проверка с сохранностью оригинала.
- Потеря ответа после записи на сервере, обрыв polling, две вкладки и конфликт редактирования, одновременные сдачи двух учеников.
- Группы, учебный план, граф навыков, каталог, обсуждения, экспорт JSON; отмена занятия, все отметки ручной оплаты и календарь ICS; валидация и скачивание TXT.
- Родитель: подмена ребёнка, отзыв доступа и обрыв сети; смена выбранного ребёнка при задержанном ответе. Коллега: копирование шаблона и отказ после исключения из пространства.
- Политики подсказок: эталон не показывается ученику, подсказки автора доступны согласно настройке, обратная связь появляется после решения преподавателя.

Проверки выполнены отдельным headless Chrome, одним worker, на синтетической SQLite. AI в этом аудите — детерминированный тестовый провайдер, без вызовов OpenRouter. Трассы кадров и шагов сохранены в `artifacts/deep-audit/*-traces`. Кадры учебного плана просмотрены; визуальный просмотр каждого экрана пока не завершён.

## Повторить локально

Только отдельная тестовая база. Не публиковать модуль audit_server и не использовать реальные данные.

```sh
npm run build
.venv/bin/python -m uvicorn tests.audit_server:app --host 127.0.0.1 --port 8017 --no-access-log
```

Во втором терминале:

```sh
E2E_URL=http://127.0.0.1:8017 E2E_AUDIT=1 E2E_MAX_SIM=true E2E_FAULT_SIM=true E2E_FIXTURE_GENERATION=1 E2E_MAX_SDK_PATH=artifacts/max-web-app.js npx playwright test --workers=1
.venv/bin/python -m pytest -q
```

Перед каждым тестом синтетическая база сбрасывается. `artifacts/max-web-app.js` — сохранённый SDK для контрактной проверки. Тестовый wrapper переводит только loopback Origin в synthetic audit.invalid; это не проверка боевого HTTPS/Origin.
