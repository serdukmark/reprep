# Проверка отказов — 20 сентября 2026

Это контролируемые локальные отказы, не аварии настоящего OpenRouter. Платных запросов на этом этапе нет. Основной тест проходит через API сдачи, SQLite, реальную очередь, OpenRouterAdapter и HTTP MockTransport; затем преподаватель сохраняет ручную проверку, ученик получает её через API.

| Случай | Проверяемый контракт |
|---|---|
| Нет соединения, HTTP 503/429 | Оригинал неизменен, provider_unavailable, работа ждёт преподавателя |
| Обрыв чтения и ReadTimeout | Тот же переход, без текста upstream/секретов в логах |
| Пустота, HTML вместо JSON, неверная схема, повреждённый конверт | output_invalid, нет ложной оценки и кнопки подтверждения пустого результата |
| Контекст >60 000 UTF-8 байт | Ни одного HTTP-вызова; context_too_large; все ответы доступны ручной проверке |
| Два ученика одновременно | Два разных задания/оригинала, по одному вызову каждого; ошибка первого не мешает второму, доступ и прогресс разделены |

`tests/test_failure_paths.py`: 11 сценариев отказов/конкуренции; отдельно проверена приватность несданного черновика. Для каждого отказа проверяются отсутствие автоматического прогресса, сокрытие сырого AI от ученика и завершение ручного цикла. Повреждённый конверт ранее ошибочно относился к недоступности провайдера; теперь он явно считается невалидным ответом. Поля choices/message/output проверяются по типу, неисправное поле usage не ломает разбор.

`python scripts/test_failure_mutations.py` (использовать .venv/bin/python): каждый из десяти отказов запускается на копии кода с намеренно зависающим статусом. Ещё три мутации убирают лимит контекста, стирают оригинал, обновляют чужую работу. Требуется именно AssertionError теста, не ошибка импорта/сборки. Рабочий код не меняется. Это проверка чувствительности контрактов, не доказательство отсутствия всех ошибок.

Браузерная проверка: `.venv/bin/python -m uvicorn tests.fault_server:app --host 127.0.0.1 --port 8002`, затем `E2E_URL=http://127.0.0.1:8002 E2E_FAULT_SIM=true npm run test:e2e -- tests/browser/failure.spec.ts`. Этот специальный сервер всегда имитирует отказ провайдера, использует отдельную artifacts/failure-browser.sqlite3 и **не подходит для показа живого AI**. Production Docker его не содержит.

Ограничения: MockTransport не воспроизводит DNS/TLS/реальную маршрутизацию и все тайминги. Одновременные две сдачи — не нагрузочное испытание. SQLite аварийное восстановление/заполненный диск не испытаны. Тайм-аут coroutine не способен принудительно убить зависший поток адаптера; для длительной эксплуатации нужен отдельный процесс/очередь с ограниченным жизненным циклом.

Браузерный сценарий прошёл (26.3 с), скриншот просмотрен. Зависшее сохранение прерывается через 15 с и сохраняет текст в форме; сетевые ошибки отображаются по-русски; после восстановления polling ручной цикл завершается. Проверка всех 13 мутаций прошла. Полный серверный набор: 47 passed, два предупреждения зависимостей.
