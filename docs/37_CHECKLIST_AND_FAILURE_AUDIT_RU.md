# Повторная сверка и отказы — 22.09.2026

## Работает и проверено

**Боевой HTTPS:** сохранённый основной прогон `docs/evidence/public-rehearsal.json`: 51 API-шаг, 12,78 с, ожидание Qwen 7,14 с, самая долгая отдельная HTTP-операция 0,483 с. Назначение → черновик → сдача → настоящий AI → исправление от роли преподавателя → подтверждённый прогресс. Подтверждение выполнено API от тестовой роли, не независимым человеком. Вход через MAX не использовался: оператор создал отдельные явно синтетические аккаунты и короткие сессии. Публичные демо-входы и политика данных не менялись. Все сессии отозваны.

Дополнительный HTTPS-прогон `docs/evidence/public-network-recovery.json`: 1,051 с, без AI. Реальный PUT сохранил черновик, затем тестовый транспорт клиента отбросил полученный ответ и выбросил ReadError. Другой клиент прочитал сохранённый ответ, устаревшая запись получила 409. После имитации offline новым HTTP-клиентом восстановлено сохранённое состояние, попытка сдачи не создалась. Это управляемая потеря подтверждения клиентом, не физическое отключение сетевого адаптера и не тест браузерного интерфейса.

Прогоны шли с Mac через публичный HTTPS, Host/SNI и проверка сертификата сохранены. В resolver только тестового процесса задан IP VM из-за диагностированного сбоя системного DNS Mac; hosts/маршруты не менялись. DNS-ограничение нельзя скрывать за словом «полностью».

**Права на HTTPS:** чужой преподаватель/второй ученик не открывают работу/сдачу по прямому API URL; родитель видит подтверждённую сводку, но не исходную работу; после отзыва две родительские сессии получают 404 и пустой экспорт работ. Коллега видит только шаблон; исходная работа закрыта. После исключения обе его сессии теряют templates/members/invitations и возможность копирования. Доказательства — HTTP-статусы в основном прогоне.

**Изолированные отказы:** 20 целевых серверных тестов прошли (3,59 с): tests/test_failure_paths.py, test_rehearsal_failures.py, test_guardian.py, test_workspaces.py. Connect/read errors, timeout, HTTP 429/503, пустота/мусор/неверная структура, слишком длинная работа → ручной разбор с сохранением оригинала. Медленная модель не блокирует API и не перезаписывает решение преподавателя поздним результатом. Скрипт test_failure_mutations.py обнаружил все 13 намеренных повреждений. Рабочее дерево и публичный процесс при мутациях не меняются.

**Полная серверная регрессия:** 145 passed, 9,14 с; artifacts/checklist-audit-pytest.xml. Предупреждения — deprecated API зависимостей TestClient; не падения. Браузерные тесты не запускались из-за запрета синтетического ввода.
