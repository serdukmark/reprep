# Черновики и элементы выбора — 24.09.2026

Причина недоступной кнопки: до принятия первого приглашения список учеников пуст, кнопка была disabled. Теперь новый преподаватель может открыть редактор и сохранить черновик без ученика. Назначить работу можно после выбора подключённого ученика. Черновик не виден другим пользователям.

Общие выпадающие списки заменены ChoiceSelect с единым стилем: статусы работ, ученик, тип задания, обратная связь, уроки, материалы, планы, группы, каталог, граф навыков и библиотека коллег. Изменения общие для MAX и Telegram. Telegram остаётся только временным тестовым каналом по решению владельца.

Локально проверено: 154 серверных теста, сборка TypeScript/Vite, статический мобильный снимок закрытых полей. Миграция 11 проверена на старой структуре: данные и ссылки сохраняются; перед выкаткой сделан приватный backup базы на VM с integrity_check. Управление живыми окнами не выполнялось, реальный touch/keyboard-прогон custom select в мессенджере не заявлен.

Воспроизвести: новый преподаватель → Создать задание → указать название и задачу → Сохранить черновик → открыть сохранённое. Без ученика назначение недоступно и объяснено. После принятия приглашения учеником → Редактировать → выбрать ученика → Назначить.

Выкатка выполнена на https://reprep.ru/. Внешний HTTPS-прогон на приватном синтетическом преподавателе без учеников: создание 201, чтение 200, черновик присутствует в списке, назначение без ученика 422 LEARNER_REQUIRED. Сессия отозвана. Свидетельство: evidence/unassigned-draft-public.json. Миграция 11 применена, PRAGMA integrity_check и foreign_key_check на VM прошли.
