## Выключенная механика

Ревью исходной механики выявило два изменения, первоначально действовавших
при `false`: объединение результатов навыка без учёта регистра и отслеживание
ID возвращённой попытки. Для условия «до сдачи только оформление» они также
ограничены флагом:

- `/skill-graph` при `false` сохраняет прежние расчёты и форму ответа без
  `evidence_ids`; при `true` включает объединение evidence и новые ID.
- `AssignmentDetail` при `false` использует прежнее условие сброса по статусу;
  receipt и дополнительное сравнение ID доступны только при `true`.
- Endpoint серии при `false` отвечает 404; клиент не запрашивает его и не
  показывает серию, путь или новый экран подтверждения. Миграций БД нет.

Тесты проверяют полный ответ графа до включения, после включения и после
обратного выключения: последний ответ равен исходному. Оформление прежнего
SVG-графа получает токены в обоих режимах — это часть переноса оформления.

## Передача и ограничения

Ручная приёмка кандидата: открыть три демо-роли, проверить маркировку,
светлую/тёмную тему и 320 px; пройти назначение → отправку → проверку → прогресс.
Для повторного мессенджерного входа использовать сохранённую синтетическую
идентичность в новой сессии, не подменяя её демо-входом. Механику при сдаче
оставить выключенной; её включённые снимки служат отдельной приёмкой.

Требования: UX/UI §1/3/7/8; FR-PROG-001/002/004/006/007,
FR-SUB-002/003/004/005, FR-AI-003/006/008, TEAM-104. Открытые вопросы
OQ-DESIGN-001, OQ-JOURNEY-001/002 и проверка настоящего MAX на устройстве
сохраняются. Новых обещаний учебной эффективности нет.

Основная ветка `feat/reprep-mvp`, стенд и архив этой сессией не изменены.
Собственные проверочные серверы после прогонов остановлены. Обновлены README,
этот отчёт, журнал решений, уточнение ADR-014 и ссылки из исходных отчётов.
Исходные отчёты сохранены как история. Код интеграционной правки затрагивает
`Assignment.tsx`, `skill_graph.py`, его вызов в `main.py`, `openapi_contract.py`
и экспорт `openapi.json`, мобильные правила шапки в `style.css`; тесты — `test_skill_graph.py`,
`design-foundation.spec.ts`, `learning-journey.spec.ts`, `release-design.spec.ts`.
Сессия выкатки должна брать точный переданный коммит, сохранить свою точку
отката, проверить `LEARNING_JOURNEY_ENABLED=false` и пересобрать архив/сумму
по процедуре владельца. Живой OpenRouter и реальный MAX входят в её проверку
стенда; локальные результаты выше не объявляются доказательством внешнего вызова.
